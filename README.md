- CSS3 (Flexbox, layout responsivo)
- [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) e [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) (Google Fonts)
